I. Packer Data
The packer data items are included to the components array of general structure.
```
{
	wellName?: string;
	wellID?: string;
	unit?: Unit;
	holes: Hole[];
	components?: any[]; <- packer data items are included to components array.
}
```

  1. This is the data Packer includes:
```
  Packer {
    type: 'Packer';
    toolType?: 'Liner Top Packer' | 'Production Packer' | 'Isolation Packer' | 'Well Test Packer';
    refCasingID: string;
    seatingCasingID?: string;
    startDepth: number;
  }
```
  2. Which includes:
    - Packer:
      + type: string
        The type of the component is `Packer`
      + toolType: string
        The pipe type of the casing, that includes 'Liner Top Packer', 'Production Packer', 'Isolation Packer', 'Well Test Packer'
      + refCasingID: string
        The reference identifier used to refer to the referred casing
      + seatingCasingID: string
        The reference identifier used to refer to seat at the outer casing
      + startDepth: number
        The start depth of the casing (it's based on the depth unit)
      
  3. Description:
    The packer specifications will be entered by the user.
  4. Guide and Default Data:
    - If the user does not mention refCasingID, then we will provide options for casings that the user wants to set.
    - If the user does not mention seatingCasingID, then we will rely on refCasingID to find the outer casing above.
  5. Validation Rules:
    - refCasingID cannot be null.
    - The start depth of the packer must be in range of the start depth to the bottom depth of the current casing.
