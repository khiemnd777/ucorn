I. Well Data
The structure of Well Data includes the following information:

```
WellData {
	wellName?: string;
	wellID?: string;
	unit?: Unit;
}
Unit {
	diameter: "inch";
	depth: "ft";
}
```

Which includes:
	- wellName: string
		The name of the well
	- wellID: string
		The identifier of the well (Optional)
	- unit: Unit
		The units of measurement such as diameter and depth.
			For diameter, the default unit is inch. However, user can change per specified need.
			For depth, the default unit is ft. However, user can change per specified need.
		Warning: Units must comply with international standards. If the user provides incorrect information, the user should be reminded and not allowed to generate JSON data.

Example:
{
    "wellName": "Sample Well",
    "wellID": "W001",
    "unit": {
        "diameter": "inch",
        "depth": "ft"
    },
}

II. Hole Data
This is the data Hole includes:
```
Hole {
  holeID?: string;
  diameter: number;
  depth: number;
  underreamed?: Underreamed[];
}
Underreamed {
  diameter: number;
  startDepth: number;
  endDepth: number;
}
```
Which includes:
	- Hole:
		+ holeID: string
			The identifier of the hole (Optional)
		+ diameter: number
			The diameter of the hole (it's based on the diameter unit)
		+ depth: number
			The depth of the hole (it's based on the diameter unit)
		+ underreamed: Underreamed
			The underreamed section under the hole.
	- Underreamed:
		+ diameter: number;
			The diameter of the underreamed section.
		+	startDepth: number
			The start point of the depth of the hole.
		+ endDepth: number
			The end point of the depth of the hole.

The hole data as array of holes will be included WellData.
Example:
	WellData {
		wellName?: string;
		wellID?: string;
		unit?: Unit;
		holes: Hole[];
	}

Description:
	- The number of holes will be defined by the user, but if they do not mention the number or any hole data definition, the default hole data will have 5 holes with diameter (default unit is inch) in order. From 32, 24, 17.5, 12.25, and 8.5 inches, if the user provides a diameter unit other than inches, it will automatically convert to the unit that the user has provided.

Validation Rules:
	- The diameter of the hole above must be larger than the diameter of the hole below.
	- The depth of the hole above must be less than the depth of the hole below.
	- The diameter of the under reamed section can be larger than the hole through which it is reamed over.
	- The start depth of the under reamed section must be in range of the depth of the hole above it and the depth of the current hole where it reams out.

	Warning: If a user asks you to update an incorrect value, you must warn the user and show them what is wrong.
